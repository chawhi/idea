# マネタイズ・ゲーム内通貨 設計書

## 基本方針

- **基本無料・広告なし**
- **課金でゲーム強さが変わらない**（バトル強さは健康データのみ）
- 課金は「見た目・快適さ・拡張」に限定
- 健康に真剣に取り組むユーザーが最も強くなれる設計

---

## ゲーム内通貨

### 2種類の通貨

| 通貨 | 名前 | 入手方法 | 用途 |
|-----|-----|---------|-----|
| 💰 **バイタコイン** | 無料通貨 | 歩数・睡眠・食事記録・バトルなど日常プレイ | ショップ一部・たまご合成 |
| 💎 **ジェム** | 有料通貨 | 課金購入 or 特別報酬（極少量） | プレミアムショップ・追加スロット |

## バイタコイン（無料通貨）

### 入手方法・レート

| 行動 | 獲得量 | 備考 |
|-----|-------|-----|
| 歩数 1,000 歩達成 | 5 コイン | 1 日上限 50 コイン（10,000 歩） |
| 睡眠 7 時間以上 | 20 コイン | 8 時間以上で +5 ボーナス |
| 食事記録 3 食 | 15 コイン | バランスボーナス達成で +10 |
| バトル勝利 | 30 コイン | 敗北でも 10 コイン |
| デイリーミッション達成 | 10〜50 コイン | ミッション難易度による |
| ウィークリーミッション | 100〜300 コイン | 週 1 回 |
| ストリーク（連続達成） | 日数 × 5 コイン | 7 日連続で 35、30 日で 150 |
| ペット進化 | 50 コイン | 進化ごとに 1 回 |
| 転生 | 200 コイン | 転生ごとに 1 回 |
| フレンド応援（受け取り） | 5 コイン/人 | 1 日最大 3 人分 |

### 1 日の平均獲得目安

```

睡眠（7.5 時間）: 22 コイン
食事記録（3 食）: 25 コイン
デイリーミッション: 30 コイン
──────────────────
合計: 約 117 コイン/日
月間: 約 3,500 コイン
```

## 経済バランス設計

### 健全なエコノミーの原則

```
1. 無課金ユーザーが 3 ヶ月で着せ替え 2〜3 点買える程度の入手量
2. 課金ユーザーは見た目の充実感が高いが、ゲーム進行は同速
3. ゲーム内インフレ防止: コイン上限・1 日獲得上限を設ける
4. 転生するとコインリセット（過去の貯蓄は一部引き継ぎ）
```

### KPI 目標（参考）

| 指標 | 目標値 |
|-----|-------|
| DAU/MAU 比率 | 40%以上（健康習慣継続が前提） |
| ARPPU | ¥1,500/月 |
| 課金転換率 | 3〜5% |
| サブスク継続率 | 70%/月 |
