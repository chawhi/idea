# デジタルペット育成アプリ コンセプト仕様書

## アプリ概要

**アプリ名（仮）**: VitaPet（バイタペット）
**プラットフォーム**: iOS + Apple Watch
**ジャンル**: ヘルスケア連動型デジタルペット育成ゲーム
**コンセプト**: 「自分が健康になるほど、ペットも強く・かわいくなる」

---

## 世界観・テーマ

- **スタイル**: かわいい系（たまごっち・ポケモン・デジモン寄りのデフォルメキャラ）
- **世界観**: ファンタジーな小世界に住む不思議な生き物を育てる
- **トーン**: 明るく・ポップ・癒し系。ゲームに疲れたユーザーの日常に馴染む

---

## コアゲームループ

```
[ユーザーの日常行動]
  歩く / 寝る / 食事を記録する
       ↓
[HealthKit / Apple Watch でデータ取得]
       ↓
[ペットへの影響]
  ごはんをあげる / トレーニングする / アイテム入手
       ↓
[ペットが成長・進化]
  見た目・ステータス・スキルが変化
       ↓
[完全体に到達 → 引退・転生]
  能力を引き継ぎ、新しいたまごへ
```

## ペット仕様

### 初期選択（5種族）

ゲーム開始時にたまごの種族を5種類から選ぶ。種族ごとにベースステータスと進化ルートが異なる。

| 種族名 | 特徴 | 得意分野 | イメージ |
|-------|------|---------|---------|
| **フレア**（炎系） | 情熱的・元気 | 運動・アクティブ型進化に強い | 小さな炎がまとわりつくキャラ |
| **マリン**（水系） | 穏やか・柔軟 | 睡眠・回復型進化に強い | 水玉や雫モチーフのキャラ |
| **テラ**（大地系） | どっしり・安定 | バランス型進化に強い | まるっとした土・岩モチーフ |
| **シルフ**（風系） | すばしっこい・自由 | 歩数・スタンド達成に強い | 羽や葉っぱがついた小動物 |
| **ルナ**（月系） | ミステリアス | 食事バランス・隠しルートに強い | 星や月のモチーフ、夜に輝く |

### 成長段階（デジモン型・分岐進化）

| ステージ | 目安期間 | 説明 |
|---------|---------|------|
| たまご | 〜1日 | 孵化待ち状態（歩数で短縮可能） |
| 赤ちゃん | 〜3日 | 最も基本的な形態、世話が最重要 |
| 子供 | 〜7日 | 個性が出始める |
| 少年/少女 | 〜14日 | 進化分岐の岐路 |
| 成熟 | 〜30日 | 本格的な見た目・能力が確定 |
| 完全体 | 長期 | 最終形態（種族×育て方で多数） |

### 進化分岐（育て方で変わる）

各種族につき分岐があり、組み合わせで多くの完全体が存在する。

- **バランス型** → 歩数・睡眠・食事がすべて安定していると進化
- **アクティブ型** → 歩数・運動量が特に多いと進化（筋肉質・スポーティな見た目）
- **安眠型** → 睡眠スコアが高いと進化（おっとり・ふっくらした見た目）
- **グルメ型** → 食事記録が豊富・栄養バランスが良いと進化（おいしそうな見た目）
- **放置型** → データが不足すると進化（ひょろひょろ・眠そうな見た目）※ネガティブ進化も

### 転生（リセット）システム

完全体に到達したペットは「引退」し、転生できる。

```
完全体に到達
    ↓
[転生する] を選択
    ↓
能力の一部を「遺産スキル」として引き継ぐ
    ↓
新しいたまごを獲得（成長段階に応じてレア度が変わる）
    ↓
再び育成スタート（引き継いだスキル分だけ有利に）
```

#### 遺産引き継ぎ内容

| 引退時の段階 | 引き継げるもの |
|------------|-------------|
| 成熟で引退 | ステータス上限 +5%、スキル1つ |
| 完全体で引退 | ステータス上限 +10%、スキル2つ、称号 |
| 完全体 × 連続ストリーク | ボーナス遺産スキル、レアたまご確定 |

#### 新しいたまごのレア度

- **ノーマルたまご**: 初回 or 引退ペットのスコアが低い場合
- **シルバーたまご**: 完全体で引退した場合
- **ゴールドたまご**: 高スコア完全体 or 特定条件達成
- **レインボーたまご**: 複数回転生 + 高実績 → 超レア進化先が解放

## ヘルスケア連動仕様

### データソース（HealthKit）

| データ種別 | 取得元 | ゲーム内効果 |
|----------|-------|------------|
| 歩数 | iPhone / Apple Watch | ペットの「ご飯」として変換 |
| 睡眠時間・質 | Apple Watch | ペットの「睡眠ゲージ」回復 |
| アクティブカロリー | Apple Watch | 「トレーニングアイテム」入手 |
| 食事記録 | アプリ内入力（テキスト/カメラ/栄養成分表読取） | 「食材アイテム」入手、栄養バランスでボーナス |
| 心拍数 | Apple Watch | ペットの「ストレスゲージ」に影響 |
| ムーブ・スタンド | Apple Watch | 隠しアイテム出現条件 |

### ゲーム内変換レート

- 歩数 1,000歩 → ご飯アイテム × 1
- 睡眠 7時間以上 → 「ぐっすりの実」（回復アイテム）
- 運動 30分以上 → 「きんにくのかけら」（強化アイテム）
- 食事記録 3食 → 「バランスボーナス」（経験値 +50%）
- 栄養バランス優秀（PFC比が適切） → レアアイテム抽選

---

## 食事記録システム

### 3種類の入力方法

#### 1. テキスト入力
- 食品名を手入力 → 内蔵DBから栄養素を自動補完
- 量（g / 個数 / 大さじなど）を選択

#### 2. カメラ撮影（料理写真）
- 料理の写真を撮影 → AI推定で食品・量を提案
- ユーザーが確認・修正して確定

#### 3. 栄養成分表スキャン（バーコード / ラベル読取）
- 食品パッケージのバーコードをスキャン → 栄養成分DBと照合
- 栄養成分表示のテキストをOCR読取 → カロリー・PFCを自動入力
- コンビニ・市販食品に特に有効

### 栄養データのゲーム反映

| 栄養状態 | ゲーム内効果 |
|---------|-----------|
| 3食バランス良く記録 | 経験値ボーナス |
| タンパク質多め | 「きんにくのかけら」入手確率UP |
| 野菜・食物繊維多め | 「ちからの葉っぱ」アイテム |
| 偏った食事が続く | ペットの体調ゲージに影響 |
| 1食でも記録なし | その日のボーナスが減少 |

## ペットのステータス

| ステータス | 説明 | 影響する行動 |
|----------|------|-----------|
| お腹 | 空腹度。0になると機嫌が悪くなる | 歩数→ご飯 |
| 体力 | 疲労度。低いとトレーニング不可 | 睡眠データ |
| 幸福度 | 遊んだり話しかけると上昇 | アプリ内操作 |
| 体重 | 食べすぎると上昇、運動で減少 | 歩数・食事 |
| 経験値 | たまると次の進化段階へ | 全行動 |
| 遺産スキルLv | 転生回数と実績で上昇 | 累積プレイ |

## オンライン・ソーシャル機能

### フレンドシステム
- フレンドコードで友達を追加
- フレンドのペットの状態をリスト表示（今日の歩数・ペットの調子）
- 「応援する」機能 → 相手のペットに回復アイテムをプレゼント

### ペットバトル
- フレンドまたはランダムマッチングで対戦
- バトルは**ターン制オート**（プレイヤーはスキルと戦略を設定するだけ）
- 強さは育て方のステータスに基づく（課金有利にならない設計）
- 週次ランキングで上位入賞 → レアアイテム報酬

### バトルの仕組み
```
事前に「バトルデッキ」設定（スキル3つ選択）
    ↓
マッチング → オートバトル（アニメーション観戦）
    ↓
勝敗 → バトルポイント獲得 → 週次ランキング反映
```

### コミュニティ
- ペットの写真・進化をSNS風フィードでシェア
- 「いいね」「コメント」機能
- ハッシュタグでレア進化を見せ合う文化

## ゲームプレイ機能

### iPhone アプリ（メイン）
- ペットのホーム画面（背景・ステージが成長で変化）
- ご飯をあげる・遊ぶ・話しかけるなどのインタラクション
- 図鑑（進化先・種族・転生履歴の確認、未発見は「？」表示）
- アイテム管理・使用
- 食事記録（テキスト / カメラ / 栄養成分表スキャン）
- 日々の健康サマリーとペットへの影響レポート
- バトル画面・フレンドリスト
- ショップ（ゲーム内通貨で着せ替え・部屋デコ購入）

### Apple Watch アプリ（サブ＆通知）
- 文字盤コンプリケーション（ペットの顔・ステータスバーを常時表示）
- ヘルスデータのリアルタイム反映（歩数がたまるとペットにアニメーション）
- ペットからの通知（お腹空いた / 遊んで！ / 調子いいよ！）
- ミニインタラクション（Watch上でなでる・ご飯をあげる）
- ワークアウト連携（ワークアウト中はペットが「一緒にトレーニング」アニメーション）

## モチベーション維持設計

- **デイリーミッション**: 「今日6,000歩歩く」「7時間寝る」「3食記録する」などの目標
- **ストリーク**: 連続達成日数でレアアイテム・転生ボーナス付与
- **ペットの感情表現**: 世話をサボるとペットが寂しそうに（責めすぎず、ユーモアで）
- **転生モチベ**: 完全体になっても「次の転生でもっと強く」という継続目標
- **週次レポート**: 「今週8,000歩/日！ペットの体力+20、転生ポイント+15」
- **フレンドとの比較**: フレンドの歩数・ペット状態を見て刺激を受ける

## マネタイズ（案）

- **基本無料**
- 着せ替えアイテム・部屋デコのショップ販売（買い切り）
- 広告なし or プレミアムプランで広告完全除去
- サブスク（月額）: 追加ペット枠・特別進化ルート・食事記録AI精度UP・バックアップ機能
