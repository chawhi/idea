# デジタルペット育成アプリ コンセプト仕様書

## アプリ概要

**アプリ名（仮）**: VitaPet（バイタペット）
**プラットフォーム**: iOS + Apple Watch
**ジャンル**: ヘルスケア連動型デジタルペット育成ゲーム
**コンセプト**: 「自分が健康になるほど、ペットも強く・かわいくなる」

---

## 世界観・テーマ

- **スタイル**: かわいい系（たまごっち・ポケモン・デジモン寄りのデフォルメキャラ）
- **世界観**: ファンタジーな小世界に住む不思議な生き物を育てる
- **トーン**: 明るく・ポップ・癒し系。ゲームに疲れたユーザーの日常に馴染む

---

## コアゲームループ

```
[ユーザーの日常行動]
  歩く / 寝る / 食事を記録する
       ↓
[HealthKit / Apple Watch でデータ取得]
       ↓
[ペットへの影響]
  ごはんをあげる / トレーニングする / アイテム入手
       ↓
[ペットが成長・進化]
  見た目・ステータス・スキルが変化
       ↓
[モチベーション維持]
  もっと健康に動きたくなる
```

## ペット仕様

### 初期設定
- **たまご**から始まる（孵化まで最低24時間、条件達成で短縮）
- プレイヤーが好きなたまごの色・模様を選択（初期カスタマイズ）

### 成長段階（デジモン型・分岐進化）

| ステージ | 目安期間 | 説明 |
|---------|---------|------|
| たまご | 〜1日 | 孵化待ち状態 |
| 赤ちゃん | 〜3日 | 最も基本的な形態、世話が必要 |
| 子供 | 〜7日 | 個性が出始める |
| 少年/少女 | 〜14日 | 進化分岐の岐路 |
| 成熟 | 〜30日 | 本格的な見た目・能力が確定 |
| 完全体 | 長期 | 最終形態（複数種類） |

### 進化分岐（育て方で変わる）

- **バランス型** → 歩数・睡眠・食事がすべて安定していると進化
- **アクティブ型** → 歩数・運動量が特に多いと進化（筋肉質・スポーティな見た目）
- **安眠型** → 睡眠スコアが高いと進化（おっとり・ふっくらした見た目）
- **グルメ型** → 食事記録が豊富・栄養バランスが良いと進化（おいしそうな見た目）
- **放置型** → データが不足すると進化（ひょろひょろ・眠そうな見た目）※ネガティブ進化も

## ヘルスケア連動仕様

### データソース（HealthKit）

| データ種別 | 取得元 | ゲーム内効果 |
|----------|-------|------------|
| 歩数 | iPhone / Apple Watch | ペットの「ご飯」として変換（100歩 = エサ1個など） |
| 睡眠時間・質 | Apple Watch | ペットの「睡眠ゲージ」回復 |
| アクティブカロリー | Apple Watch | 「トレーニングアイテム」入手 |
| 食事記録 | アプリ内入力 or ヘルスケアアプリ連携 | 「食材アイテム」入手、栄養バランスでボーナス |
| 心拍数 | Apple Watch | ペットの「ストレスゲージ」に影響（高すぎると疲労） |
| ムーブ・スタンド | Apple Watch | 隠しアイテム出現条件 |

### ゲーム内変換レート（例）

- 歩数 1,000歩 → ご飯アイテム × 1
- 睡眠 7時間以上 → 「ぐっすりの実」（回復アイテム）
- 運動 30分以上 → 「きんにくのかけら」（強化アイテム）
- 食事記録 3食 → 「バランスボーナス」（経験値+50%）

## ペットのステータス

| ステータス | 説明 | 影響する行動 |
|----------|------|-----------|
| お腹 | 空腹度。0になると機嫌が悪くなる | 歩数→ご飯 |
| 体力 | 疲労度。低いとトレーニング不可 | 睡眠データ |
| 幸福度 | 遊んだり話しかけると上昇 | アプリ内操作 |
| 体重 | 食べすぎると上昇、運動で減少 | 歩数・食事 |
| 経験値 | たまると次の進化段階へ | 全行動 |

---

## ゲームプレイ機能

### iPhone アプリ（メイン）
- ペットのホーム画面（背景・ステージが成長で変化）
- ご飯をあげる・遊ぶ・話しかけるなどのインタラクション
- 図鑑（進化先の確認、未発見は「？」表示）
- アイテム管理・使用
- 食事記録入力（写真撮影 or テキスト入力）
- 日々の健康サマリーとペットへの影響レポート
- ショップ（ゲーム内通貨で着せ替え・部屋デコ購入）

### Apple Watch アプリ（サブ＆通知）
- 文字盤コンプリケーション（ペットの現在の顔・ステータスバーを表示）
- ヘルスデータのリアルタイム反映（歩数がたまるとペットにアニメーション）
- ペットからの通知（お腹空いた / 遊んで！ / 調子いいよ！）
- ミニインタラクション（ウォッチ上でなでる・ご飯をあげる）
- ワークアウト連携（ワークアウト中はペットが「一緒にトレーニング」アニメーション）

## アイテムシステム

### アイテム種別

| カテゴリ | 入手方法 | 効果 |
|---------|---------|------|
| 食べ物 | 歩数・食事記録 | お腹ゲージ回復 |
| 薬・回復アイテム | 睡眠スコア良好 | 体力・幸福度回復 |
| トレーニング器具 | 運動量達成 | 経験値ボーナス |
| 着せ替え衣装 | ショップ・ミッション報酬 | 見た目変更 |
| 部屋デコ | ショップ・ミッション報酬 | ホーム背景変更 |
| レアアイテム | 連続達成ボーナス | 進化先が変化 |

---

## モチベーション維持設計

- **デイリーミッション**: 「今日6,000歩歩く」「7時間寝る」などの目標提示
- **ストリーク**: 連続達成日数でレアアイテム付与
- **ペットの感情表現**: 世話をサボるとペットが寂しそうになる（責めすぎず、ユーモアで）
- **シェア機能**: ペットの進化・レア進化をSNSシェア
- **週次レポート**: 「今週あなたは8,000歩/日歩きました！ペットの体力が20上がりました」

---

## マネタイズ（案）

- **基本無料**
- 着せ替えアイテム・部屋デコのショップ販売（買い切り）
- 広告なし or プレミアムプランで広告完全除去
- サブスク（月額）: 追加ペット枠・特別進化ルート・バックアップ機能
