# バトルシステム詳細設計書

## コンセプト

**方針**: 課金で強くなれない。健康に生きた結果が強さになる。
**形式**: ターン制オートバトル（プレイヤーは事前デッキ設定のみ）
**目的**: 健康習慣継続のモチベーション補助・フレンドとの交流

---

## バトル基本ルール

- **ターン数**: 最大 10 ターン
- **勝敗**: 相手の HP を先に 0 にした方が勝ち。10 ターン終了時は HP 残量で判定
- **操作**: バトル中の操作なし。事前に設定した「バトルデッキ」が自動で発動
- **スキップ**: バトルアニメーションは早送り・スキップ可能

---

## ステータス体系

### ベースステータス

ペットの育て方（HealthKit データ）によって決まる。課金では変わらない。

| ステータス | 算出方法 |
|----------|---------|
| **最大 HP** | ペットレベル × 10 + 体力ステータス × 2 |
| **攻撃力（ATK）** | アクティブカロリー累計 ÷ 100 + 種族補正 |
| **防御力（DEF）** | 睡眠スコア累計 ÷ 50 + 種族補正 |
| **素早さ（SPD）** | 歩数累計 ÷ 5000 + 種族補正 |
| **魔力（MAG）** | 食事バランススコア累計 ÷ 30 + 種族補正 |

### 種族補正（ベースへの倍率）

| 種族 | ATK | DEF | SPD | MAG |
|-----|-----|-----|-----|-----|
| フレア | ×1.3 | ×0.9 | ×1.1 | ×0.8 |
| マリン | ×0.8 | ×1.2 | ×0.9 | ×1.3 |
| テラ | ×1.0 | ×1.4 | ×0.8 | ×1.0 |
| シルフ | ×0.9 | ×0.8 | ×1.5 | ×1.0 |
| ルナ | ×0.9 | ×1.0 | ×1.0 | ×1.4 |

### 進化形態補正

| 成長段階 | 全ステータス補正 |
|---------|--------------|
| 赤ちゃん | ×0.3 |
| 子供 | ×0.5 |
| 少年/少女 | ×0.7 |
| 成熟 | ×0.9 |
| 完全体 | ×1.0 |

### 転生ボーナス

転生するたびに基礎ステータスが加算される（上限あり）。

- 転生 1 回: 全ステータス +5%
- 転生 2 回: 全ステータス +10%
- 転生 5 回: 全ステータス +20%（上限）

## バトルデッキ

### デッキ構成
- スキルスロット × **3**（バトル中に順番通り発動）
- スキルは成長と転生で解放される

### スキル発動ルール
```
ターン 1 → デッキ スキル①
ターン 2 → デッキ スキル②
ターン 3 → デッキ スキル③
ターン 4 → デッキ スキル① （ループ）
…
```

## ダメージ計算式

### 基本ダメージ

```
ダメージ = (攻撃者のATK × スキル倍率) - (防御者のDEF × 0.5)
```

最低ダメージは 1（DEF が高くても必ず 1 入る）

### 属性相性

| 攻撃側 → 防御側 | 倍率 |
|--------------|-----|
| 炎 → 風 | ×1.5（有利） |
| 炎 → 水 | ×0.5（不利） |
| 水 → 炎 | ×1.5（有利） |
| 水 → 大地 | ×0.5（不利） |
| 大地 → 水 | ×1.5（有利） |
| 大地 → 風 | ×0.5（不利） |
| 風 → 大地 | ×1.5（有利） |
| 風 → 炎 | ×0.5（不利） |
| 月 | 属性相性なし（全属性に対してニュートラル） |

### 素早さによる先攻判定

```
SPD が高い方が先攻
同値の場合はランダム
先攻側は同ターンに相手より先にダメージを与える
```

### 会心一発（クリティカル）

```
クリティカル率 = SPD ÷ 500（上限 25%）
クリティカル時: ダメージ × 1.5
```

## バトルフロー詳細

```
[マッチング]
  └→ フレンド選択 or ランダムマッチ（近いレベル帯）

[バトル開始]
  └→ 両者のペット情報・デッキ確認画面（3 秒）

[ターン進行]
  ① 素早さ比較 → 先攻決定
  ② 先攻側スキル発動 → ダメージ計算 → アニメーション
  ③ 後攻側スキル発動 → ダメージ計算 → アニメーション
  ④ HP 確認 → どちらかが 0 以下なら終了
  ⑤ 次ターンへ（最大 10 ターン）

[バトル終了]
  └→ 勝敗画面
      ├→ 勝利: バトルポイント + コイン + 経験値
      └→ 敗北: 少量の経験値（参加ボーナス）
```

## ランキングシステム

### 週次ランキング

- 毎週月曜 0:00 リセット
- バトルポイント（BP）の累計でランキング
- 週ごとにシーズンテーマ（「炎の週」など属性に有利ルール）

### BP（バトルポイント）報酬

| 週次順位 | 報酬 |
|---------|-----|
| 1 位 | 🏆 称号 + レインボーたまご素材 × 2 |
| 2〜5 位 | ゴールドたまご素材 × 1 + コイン 500 |
| 6〜20 位 | シルバーたまご素材 × 1 + コイン 200 |
| 21〜100 位 | コイン 100 |
| 参加賞（全員） | コイン 20 |

### リーグ制（将来拡張）

- ブロンズ / シルバー / ゴールド / ダイヤ / マスターの 5 リーグ
- 勝利で昇格、連敗で降格

## 公平性の担保

| 方針 | 実装 |
|-----|-----|
| 課金で強さが変わらない | 課金は着せ替え・部屋デコのみ |
| 低レベルでも勝てる | マッチングは同成長段階内で優先 |
| 放置ペットに配慮 | 放置型完全体にも独自スキルを用意 |
| 転生回数による格差 | 転生ボーナス上限 +20% 固定 |
| 運要素の調整 | クリティカル率上限 25%、完全ランダム要素は最小限 |
