# 画面設計仕様書（ワイヤーフレーム）

## デザイン基本方針

**ビジュアルトーン**: デジモン×ポップ。暗めの背景にキャラが映える配色
**UI スタイル**: ゲームUI風（角丸パネル・グロー効果・ドット的なアイコン）
**フォント**: 丸ゴシック系（日本語）+ ゲーム風英数フォント
**カラーテーマ**: 深紺〜黒のベース + 属性カラーのアクセント（種族によって変わる）

### ペット表示エリア詳細
- タップ → なでるアニメーション
- 長押し → 話しかける（テキスト吹き出し）
- スワイプ左右 → 部屋の別アングル表示

### 背景（ステージ）の変化
| 条件 | 背景 |
|-----|-----|
| 赤ちゃん〜子供 | 小さな草原の部屋 |
| 少年 | 広い草原・森 |
| 成熟 | ダンジョン風・山岳 |
| 完全体 | 壮大な城・竜の巣 |
| 夜（21時〜） | 星空・月夜 |
| 雨の日 | 雨降りエフェクト |

### カメラ撮影フロー
```
[📷 写真で記録] タップ
    ↓
カメラ起動
    ↓
料理を撮影
    ↓
AI 解析中（ローディング）
    ↓
[推定結果]
  「ラーメン（醤油）」 700kcal
  確認して登録 / 修正する
    ↓
登録完了 → ペットにアイテムが届く演出
```

### バーコード・栄養成分表スキャンフロー
```
[📊 バーコード] タップ
    ↓
スキャン画面（バーコード or 栄養成分表どちらか選ぶ）
    ↓
スキャン成功 → 商品名・栄養素が自動入力
    ↓
量（個数 / g）を入力
    ↓
登録完了
```
