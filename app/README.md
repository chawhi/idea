# 譜面マークアップ練習ツール

コード譜・タブ譜の画像/PDFを取り込み、BPMに合わせて演奏位置を透明ハイライトで示しながら自動スクロールする、ブラウザだけで動く練習用アプリ。

## 使い方

1. 静的サーバーで配信する（ES Modules と PDF.js の Web Worker を使うため `file://` では動かない）。

   ```bash
   cd app
   python3 -m http.server 8000
   # もしくは: npx serve .
   ```

   ブラウザで `http://localhost:8000/` を開く。

2. **編集モード**でヘッダーの「譜面を取り込む」から画像（PNG/JPG）またはPDFを追加。
3. 譜面上をドラッグして、演奏順に区間（小節・行など）を矩形で囲む。右側の「区間リスト」で拍数の調整・並び替え・削除ができる。
4. **再生モード**に切り替え、BPMを設定して「再生」を押すと、現在の区間が透明な黄色でハイライトされ、自動スクロールしながら進む。

## データの保存

- 取り込んだ譜面とマークはブラウザの localStorage に自動保存される（同一ブラウザなら再訪時も残る）。
- 「書き出し」でJSONファイルとしてバックアップでき、「読み込み」で復元・別ブラウザへの移行ができる。

## 構成

- `index.html` / `style.css` — UI
- `src/main.js` — 状態管理・DOM描画・イベント処理
- `src/playback.js` — AudioContextクロックによるBPM同期の再生スケジューラ
- `src/pdfLoader.js` — PDFページ/画像を正規化してcanvasで取り込む
- `src/storage.js` — localStorage保存とJSONエクスポート/インポート
- `vendor/pdfjs/` — PDF.js（オフラインで動くようにベンダリング済み）
